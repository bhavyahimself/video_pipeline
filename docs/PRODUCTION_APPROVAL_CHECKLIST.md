# Production Approval Checklist

Use this checklist for every channel and every final render. The video is not
eligible for YouTube upload until the user approves the exact rendered file.

## Before Rendering

- [ ] Fresh VEED project created for this video
- [ ] VEED voice, project ID, export filename, and generation date recorded
- [ ] No placeholder TTS, macOS `say`, browser voice, or alternate TTS provider used
- [ ] One primary narration track planned; no reused or duplicate narration
- [ ] Required sound effects and music have a source/license record
- [ ] Beat-to-visual contract and competitor gap are complete

## Audio QA

- [ ] Complete master has been listened to, not only sampled
- [ ] No overlapping voices, duplicate TTS, clicks, clipped words, or unexpected silence
- [ ] Narration is expressive with intentional pace, emphasis, pauses, and emotional rise
- [ ] Voice remains clear on headphones, phone speakers, and in mono
- [ ] VEED narration remains the only primary spoken track
- [ ] Loudness, peak, and audio-event checks pass

## Visual QA

- [ ] Every spoken beat has directly relevant motion footage or an honest visualization
- [ ] First two seconds show the promised subject and motion
- [ ] Captions are readable, attractive, and inside safe margins
- [ ] No blank frames, destructive crops, watermarks, soft footage, or mismatched scenes
- [ ] Payoff fulfills the opening promise

## User Approval

- [ ] Exact rendered master shown to the user
- [ ] User explicitly approved this exact file: ____________________
- [ ] Approval date/time: ____________________
- [ ] Approved filename/hash: ____________________
- [ ] Only after the approval above: metadata applied and upload performed

If any box is unchecked, keep the package local and revise it. Do not upload a
"review" file and assume that private visibility replaces user approval.
